# Recovered dataset notes

The original July 2020 archive contained a speech/transcript preparation tree used alongside the text-generation experiment.

## Audio/transcript material

The recovered tree contained **416 WAV files representing 391 unique audio files**. Twenty-five WAV files appeared twice in two duplicate Corn Pop source directories.

The source sets included material labeled for:

- a Corn Pop speech/story;
- a Breakfast Club interview;
- COVID-era remarks;
- a George Floyd-related speech;
- additional compiled speech excerpts.

Several sets included both `transcript.txt` and generated pipe-delimited `transcript.csv` files pairing numbered WAV filenames with transcript lines.

## Text-model corpora

The original GPT-2 working directory also contained multiple large compiled text corpora (`joe.txt` and edited variants) used during experimentation.

The full corpora and WAV files are intentionally omitted from this code archive. They are not necessary to understand the implementation and would substantially increase repository size while republishing source speech/interview material.
