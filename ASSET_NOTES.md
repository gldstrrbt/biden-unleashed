# Omitted media / project assets from recovery batch 01

The source ZIP included several large Reallusion Character Creator / iClone project files and test media. They are not committed to the code archive because of size and because the current goal is source-code preservation.

Notable recovered-but-omitted assets included:

- multiple `.iProject` scene/project files;
- a `.ccProject` Character Creator project;
- a `.iAvatar` export;
- `.RLHead`, `.RLTalk`, and `.ct7Project` files;
- short WAV/MP3 test files used while working on audio/lip-sync integration;
- an iClone error screenshot;
- large text corpora and generated model/tokenizer working files;
- a bundled GeckoDriver binary;
- upstream `aitextgen` package documentation/setup files.

The large binary iClone/Character Creator assets are useful evidence of the media-production side of the project, but should be archived separately from source code if they are preserved long-term.
